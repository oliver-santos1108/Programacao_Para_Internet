Hoje conversamos sobre HTML, HTTP e GIT.

Sobre git dscutimos o funcionamento do git, o que é o workcopy, stage, repositório. Os comandos git utilizados são listados abaixo.

git init
cria um repositório git vazio

git add
adiciona ao stage

git commit -m "mensagem"
faz commit

git config user.name "oliver-santos1108"
configura user

git config user.email "olivercs1108@gmail.com"
configura email

git status
exibe estado do repositório

git log
lista os commits da branch atual

git remote add origin url
modiica o repoitorio pra one sera enviado

git push origin main
manda para repositorio

git clone urlDoRepositorio
clona o repoitoro para uma pata no computador

git checkout branch
recuperar a parter de um branch
