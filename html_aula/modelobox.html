Modelo em Caixa, Model Box HTML

Os elementos html são estruturados em um moelo denominado modelbox, que refere-se a característica de um elemento poe conter outros elementos, sendo que caa um possui uma etrutura interna, similar a ideia e uma caixa dentro da outra

Estrutura de um elemento HTML

Todos oss elementos HTML possue, conteúdo, padding, borda, offset. Sendo a região de conteúdo estruturada em três camadas:

  1. background-color
  2. background-image
  3. content
