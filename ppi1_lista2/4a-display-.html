Exibição

Comportamento Base (display: block): Elementos como a <div> nascem nativamente configurados como blocos. Mesmo que você não defina uma largura (width), eles automaticamente se expandem para preencher as laterais da tela inteira, impedindo que qualquer outro elemento fique ao lado deles. Reset de Margens (margin: 0): O navegador adiciona por padrão uma pequena margem branca ao redor do corpo da página (body).

No código acima, margin: 0; para fazer com que as cores fiquem coladas nas extremidades da janela. Além disso, como nenhum elemento recebeu float ou sistemas de grade/linha (Flexbox ou Grid com direções alteradas), o fluxo normal do HTML renderiza um bloco abaixo do outro na ordem em que aparecem no código.
