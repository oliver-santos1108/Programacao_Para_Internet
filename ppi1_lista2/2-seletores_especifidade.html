Especificidade de Seletores

A saída desse código é a seguinte:

Como isso acontece?

li{color:red;}
Define que todos os elementos li serão exibidos em vermelho.
.churras{color:green;}
Define que todos os elementos com a classe churras serão exibidos em verde.
.fruta{color:gray;}
Define que todos os elementos com a classe fruta serão exibidos em cinza.
li+li.churras{color: black;}
Define que os elementos li que seguem imediatamente um elemento com a classe churras serão exibidos em preto.
.churras[draggable="true"]{color: magenta;}
Define que os elementos com a classe churras e o atributo draggable="true" serão exibidos em magenta.
#lip1,#lip2,#lip3{color:blue}
Define que os elementos com os IDs lip1, lip2 e lip3 serão exibidos em azul.
#lip3.fruta{color:orange}
Define que o elemento com o ID lip3 e a classe fruta será exibido em laranja.
ol>li.churras#lip5{color:purple}
Define que o elemento com o ID lip5 e a classe churras dentro de um elemento ol será exibido em roxo.

Regras

Como o CSS escolhe qual regra aplicar quando há mais de uma regra aplicável?
Exemplo:

li{color:red;}
.churras{color:green;}

Apesar de que toda a li será exibida em vermelho, a classe churras tem maior especificidade e está sendo aplicada na cor verde, mas ainda sim nenhum elemento da saída é verde.

O que ocorre são as regras de especificidade do CSS. Elas são aplicadas nessa ordem:

1. Regra de estilo embutido (inline)

Ela é aplicada diretamente no elemento HTML, utilizando o atributo style. Exemplo:

<li style="color: red;">Item 1</li>

2. Regra de ID

Ela é aplicada a um elemento HTML com um ID específico, utilizando o seletor de ID (#). Exemplo:

#lip1{color: blue;}

3. Regra de classe, atributo ou pseudo-classe

Ela é aplicada a elementos HTML com uma classe específica, utilizando o seletor de classe (.), ou a elementos com um atributo específico, utilizando o seletor de atributo ([]), ou a pseudo-classes, utilizando o seletor de pseudo-classe (:). Exemplo:

.churras{color: green;}
.churras[draggable="true"]{color: magenta;}
li+li.churras{color: black;}

4. Regra de elemento

Ela é aplicada a todos os elementos HTML de um determinado tipo, utilizando o seletor de elemento. Exemplo:

li{color: red;}

Vamos analisar em quais regras as propriedades do CSS utilizadas no código acima se encaixam:

li{color:red;}
Regra de elemento, pois está definido por uma tag. Encaixa-se na categoria: 4. Regra de elemento.

.churras{color:green;}
Regra de classe, pois está definido pela classe churras. Encaixa-se na categoria: 3. Regra de classe, atributo ou pseudo-classe.

.fruta{color:gray;}
Regra de classe, pois está definido pela classe fruta. Encaixa-se na categoria: 3. Regra de classe, atributo ou pseudo-classe.

li+li.churras{color: black;}
Regra de classe combinada com tags, pois utiliza o combinador irmão adjacente (+) e a classe churras. Como a classe dita a força do seletor, encaixa-se na categoria: 3. Regra de classe, atributo ou pseudo-classe.

.churras[draggable="true"]{color: magenta;}
Regra de atributo combinada com classe, pois está definido pelo atributo draggable e pela classe churras. Encaixa-se na categoria: 3. Regra de classe, atributo ou pseudo-classe.

#lip1,#lip2,#lip3{color:blue}
Regra de ID agrupada, que define que os elementos com os IDs individuais lip1, lip2 e lip3 serão exibidos em azul. Encaixa-se na categoria: 2. Regra de ID.

#lip3.fruta{color:orange}
Regra de ID combinada com classe, que define que o elemento com o ID lip3 e que também possua a classe fruta será exibido em laranja. Encaixa-se na categoria: 2. Regra de ID.

ol>li.churras#lip5{color:purple}
Regra de ID com seletores de herança, que define que o elemento com o ID lip5 e a classe churras, estruturado dentro de um elemento pai ol, será exibido em roxo. Encaixa-se na categoria: 2. Regra de ID.
