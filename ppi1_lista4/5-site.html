1. História da Web e Conceitos Fundamentais

Linha do Tempo e Origens

  • ARPANET (1969): Criada pelo Departamento de Defesa dos EUA para interligar laboratórios de pesquisa através de uma rede distribuída e não centralizada.
  • TCP/IP e Expansão: Nos anos 80, a adoção do protocolo TCP/IP consolidou a Internet. Chegou ao Brasil em 1988 e foi liberada comercialmente em 1994.
  • Serviços Primitivos: Antes da Web, utilizavam-se serviços como e-mail, mIRC, Gopher e FTP.

Criação da World Wide Web (WWW)

  • Em 1989, Tim Berners-Lee inventou a WWW no CERN para facilitar o compartilhamento de documentos e conhecimento via hipertexto.
  • Em 1990, desenvolveu o primeiro servidor/cliente HTTP e a linguagem HTML.
  • Em 1994, fundou a W3C para criar e manter os padrões abertos da Web.

Internet vs. Web & Arquitetura Cliente-Servidor

A Internet é a infraestrutura física/lógica de redes, enquanto a Web é o sistema de documentos de hipertexto executado sobre ela. Na arquitetura Cliente-Servidor, o cliente (navegador) envia requisições HTTP (GET, POST) e o servidor processa e retorna uma resposta com o conteúdo da página.

2. Estrutura e Elementos do HTML

O HTML (HyperText Markup Language) é uma linguagem de marcação que utiliza tags para estruturar elementos na página.

Estrutura Básica de um Documento HTML

<!DOCTYPE html>
<html lang="pt-BR">
<head>
  <meta charset="UTF-8">
  <title>Título da Página</title>
</head>
<body>
  <h1>Título Principal</h1>
  <p>Parágrafo de texto.</p>
</body>
</html>

Principais Tags HTML

Estruturais e Texto

  • <h1> a <h6>: Cabeçalhos de tópicos
  • <p>: Parágrafo | <br>: Quebra de linha | <hr>: Linha horizontal divisória
  • <pre>: Preserva o texto pré-formatado com espaços e quebras

Formatação de Texto

  • <b> / <strong>: Texto em negrito / destaque importante
  • <i> / <em>: Itálico / ênfase
  • <mark>: Texto marcado | <small>: Texto menor
  • <del>: Texto riscado | <ins>: Texto sublinhado ou inserido
  • <sub> / <sup>: Subscrito / Sobrescrito

Listas, Mídia e Tabelas

  • <ul>, <ol> e <li>: Listas desordenadas e ordenadas
  • <dl>, <dt> e <dd>: Listas de definição (termo e descrição)
  • <a> e <img>: Links e imagens
  • <table>, <tr>, <td> e <th>: Construção de tabelas com mesclagem via colspan e rowspan

3. Formulários e Entradas de Dados (<form> e <input>)

Os formulários permitem coletar dados do utilizador através dos atributos action (destino) e method (GET ou POST).

Tipo (type="") Descrição / Aplicação
text / password Campo de texto curto / Oculta os carateres digitados
email / tel / url Entradas com validação específica de formato
checkbox / radio Seleção múltipla / Seleção de opção única
file Envio de ficheiros do dispositivo
date / time / datetime-local Seleção gráfica de datas e horários
number / range Valores numéricos e barras deslizantes de seleção
submit / reset / button Botões para envio, limpeza de formulário ou ações em JS

4. Evolução do Posicionamento e Layouts CSS

  • Anos 90: Fluxo normal de posicionamento sequencial (de cima para baixo).
  • CSS1 (1996): Surgimento do float para alinhar elementos e contornar texto.
  • CSS2 (1998): Introdução do position (static, relative, absolute, fixed) e do z-index.
  • Position Sticky (2014-2017): Híbrido entre relative e fixed que reage à rolagem da página.
  • Flexbox (2009+): Modelo unidimensional ideal para distribuir espaços e alinhar itens em linha ou coluna.
  • CSS Grid (2017): Modelo bidimensional poderoso para a construção de grelhas e layouts complexos (linhas e colunas).

5. Design Responsivo com Media Queries

Permite adaptar a apresentação da página conforme o tamanho do ecrã do dispositivo:

Exemplos de Regras em CSS:

@media (max-width: 767px) {
  body { background-color: lightgreen; }
}

@media (min-width: 768px) and (max-width: 1024px) {
  body { background-color: lightyellow; }
}

@media (min-width: 1025px) {
  body { background-color: lightblue; }
}
