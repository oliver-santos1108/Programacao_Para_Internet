O que é JavaScript?

Antes do JavaScript

Antes de 1995, a Web era composta por páginas estáticas, exigindo uma requisição ao servidor após qualquer alteração. Assim, não era possível:

  1. Atualizar conteúdo dinamicamente
  2. Mostrar ou esconder elementos da página
  3. Reagir a eventos do usuário
  4. Validar formulários no cliente

Como surgiu

A Netscape contratou Brendan Eich para criar uma linguagem e script para o navegador. E em apenas 10 dias, ele escreveu a primeira versão.

Navegador X Servidor

Navegador: É a interface direta com o usuário. Quando o JavaScript roda no navegador, ele processa tudo na máquina de quem está acessando. É o responsável pela interatividade instantânea: menus que se abrem, animações, validações de formulários e atualizações visuais na tela em tempo real.

Servidor: É a central de processamento que fica na nuvem. Quando o código roda no servidor, ele lida com a lógica que o usuário não vê. Ele gerencia o acesso a bancos de dados, processa regras de segurança, autentica contas e envia as informações corretas que o navegador precisa exibir.

Sandbox

Um sandbox é um mecanismo de segurança usado para executar um aplicativo em um ambiente restrito. Assim como a caixa de areia física em um playground, em que as crianças podem criar o que quiserem dentro do limite sem fazer bagunça em outro lugar, o código do aplicativo tem a liberdade de ser executado em um ambiente restrito. Por exemplo, o JavaScript pode adicionar e modificar elementos na página, mas talvez não tenha acesso a um arquivo JSON externo. Isso ocorre devido a um recurso de sandbox chamado "mesma origem".

Objetos globais

Um objeto global em JavaScript é um objeto nativo que fica sempre disponível em qualquer parte do seu código, independentemente do arquivo ou função onde você esteja escrevendo. Ele serve como o "ambiente principal" do programa e fornece as ferramentas básicas da linguagem sem que você precise importar ou criar nada

Document

O document é um objeto global disponível apenas no navegador que funciona como a representação oficial da sua página web dentro do JavaScript. Ele serve como a porta de entrada principal para o DOM (Document Object Model), representando toda a página HTML carregada na aba atual.

Console

O console é um objeto global que funciona como a ferramenta de diagnóstico e comunicação do JavaScript. Ele serve para o programador conversar diretamente com o ambiente onde o código está rodando, permitindo enviar mensagens, testar dados e encontrar erros.

Alert

Assim como o document, o alert() é uma ferramenta exclusiva do ambiente do navegador (ela faz parte do objeto window). Se você tentar usá-la no Node.js, receberá um erro de que a função não existe, pois servidores não têm uma interface gráfica para abrir janelinhas pop-up.
