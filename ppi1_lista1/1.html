INTERNET vs WEB

A Internet é a infraestrutura física e global de redes de computadores, que permite a transmissão de dados e a oferta de serviços.

A WEB é um sistema de gerenciamento de informações onde o usuário pode solicitar uma informação ao servidor e é respondido conforme determinados comandos.

História da Internet

A história da Internet começou em 1969 com a ARPANET, uma rede criada pelo Departamento de Defesa dos EUA para interconectar centros de pesquisa universitários de forma descentralizada durante a Guerra Fria.

Em 1983, a ARPANET adotou o protocolo TCP/IP, que se tornou o padrão para a comunicação na Internet.

História da Web

Em 1990, Tim Berners-Lee inventou a World Wide Web (WWW), permitindo a criação de páginas interligadas por hyperlinks.

Linha do tempo

1969 - ARPANET
Criação da primeira rede descentralizada de computadores pelos EUA.
1983 - Padronização TCP/IP
Adoção do protocolo padrão que unificou as comunicações na Internet.
1989/1990 - Invenção da Web
Berners-Lee desenvolveu a linguagem HTML, o servidor HTTP e o primeiro navegador no CERN.
1993 - Navegador Gráfico (Mosaic)
Popularização da Web para o público geral com a primeira interface gráfica moderna.
1994 - Comercialização
Abertura da rede para empresas, e-commerce e provedores privados pelo mundo.

Pilares da Web

  1. HTTP: Protocolo de comunicação entre cliente e servidor.
  2. HTML: Linguagem para estruturar e publicar o conteúdo das páginas.
  3. URL: Sistema de identificação único para encontrar recursos na rede.
